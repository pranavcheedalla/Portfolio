Bluebonnet · safety

Rules run before the model

Emergencies, clinical questions, price quotes, coverage promises, PHI, and injection attempts are matched by deterministic keyword rules before any LLM call.

The riskiest calls never depend on a model getting it right. They route to staff with full confidence, at zero latency and zero token cost.

router.py · hard_route_rules
Bluebonnet · failure modes

When in doubt, hand it to a human

The Haiku router is told to prefer ROUTE when a case is ambiguous, and any API error or parse failure falls back to ROUTE with confidence 0.

For a dental office, a wrong answer costs more than a transfer. The system fails toward the safe outcome.

router.py · classify()
Bluebonnet · latency

Speak the first sentence first

Sonnet's reply is streamed and cut at sentence boundaries, and each sentence goes to speech as soon as it's complete. If the caller barges in, the unspoken buffer is dropped.

Callers hear a response almost immediately instead of waiting for the full answer, and the agent stops talking when interrupted, like a person would.

agent.py · _sentence_end()
Bluebonnet · measurement

Every call leaves a receipt

Each call writes a JSON value receipt with per-turn action, reason, latency, outcome, and handoff context for staff.

Impact like the 18% drop in call-handling time is measured from logs, not estimated.

receipt.py · ValueReceipt
Crestline · evals

Hard gates block the ship

A 10-scenario gauntlet tests the agent against bad data, API failures, replanning, and injection. Three scenarios are hard gates, and failing any one marks the build unshippable.

The worst failure is a quiet one: an API returning zero sales looks like "no reorders needed." The gauntlet makes that a release blocker.

run_gauntlet.py · HARD_GATES
